# 🛡️ EazyWeb — Benteng Pertahanan Isekai (`EazyBlock`)

Kumpulan daftar blokir garis depan untuk menangkap domain judi online (*judol*), situs penipuan (*scam*), dan iklan membandel yang **belum terindeks** oleh daftar pemblokir global seperti HaGeZi maupun ABPindo.

> **Cara Kerja Berjenjang:** Daftar ini adalah sumber hulu eksklusif untuk **[WhaleList (EazyLife DNS Blocklists)](https://github.com/lonion-1/WhaleList)**. Setiap minggunya, bot secara otomatis memindai sumber global; jika domain di `EazyBlock.txt` sudah resmi ditangkap oleh HaGeZi atau ABPindo, domain tersebut akan dihapus dari sini agar tetap ramping tanpa duplikasi dan dicatat riwayatnya di **[`Graduated.txt`](./Graduated.txt)**.

---

### 📦 Daftar Tautan & Statistik

| File | Format | Aturan Aktif | Ukuran | Raw URL |
| :--- | :--- | :--- | :--- | :--- |
| **`EazyBlock.txt`** | Adblock (`\|\|domain^`) | <!-- COUNT:EazyBlock.txt -->-<!-- /COUNT --> | <!-- SIZE:EazyBlock.txt -->-<!-- /SIZE --> | `https://raw.githubusercontent.com/lonion-1/EazyWeb/blocker/EazyBlock.txt` |
| **`domains/EazyBlock.txt`** | Wildcard (`*.domain`) | *Sama* | *Otomatis* | `https://raw.githubusercontent.com/lonion-1/EazyWeb/blocker/domains/EazyBlock.txt` |

> **Pengguna `personalDNSfilter`?** Gunakan tautan versi *wildcard* (`domains/EazyBlock.txt`) pada baris kedua.

---

### 🚨 Menemukan Situs Judol / Iklan yang Lolos?
Tidak perlu repot menyunting kode secara manual. Laporkan domain atau URL membandel melalui **[Form Lapor Domain Baru](https://github.com/lonion-1/EazyWeb/issues/new?template=lapor-domain.yml)**—bot akan otomatis memeriksa duplikasi, memvalidasi format, dan menambahkannya ke dalam benteng.
